# 통인 고객DB 문자 자동등록 앱

갤럭시 문자 앱에 통인CS·이사 관련 메시지 알림이 도착하면 내용을 휴대폰 내부에 임시 저장하고 고객DB 알림을 표시합니다. 알림을 누르면 고객DB의 문자 자동등록 화면에 내용을 채우고 기존 분석 기능을 실행합니다.

## 개인정보 처리

- 문자와 고객정보를 별도 외부 데이터베이스로 전송하지 않습니다.
- 고객DB 데이터는 이 앱의 WebView 저장공간에 보관됩니다.
- PC 브라우저 또는 기존 홈 화면 바로가기 데이터와 동기화되지 않습니다.
- 앱을 삭제하거나 앱 데이터를 지우면 저장된 고객정보도 삭제됩니다.

## GitHub Actions에서 APK 만들기

1. 이 폴더의 내용 전체를 GitHub 저장소 최상단에 업로드합니다.
2. 저장소의 Actions 탭에서 `Build Android APK` 작업을 엽니다.
3. 완료 후 Artifacts의 `tongin-customer-sms-debug`를 내려받습니다.
4. ZIP 압축을 풀고 `app-debug.apk`를 갤럭시로 옮겨 설치합니다.

앱 첫 실행 때 알림 권한을 허용하고, 시스템의 알림 접근 목록에서 `통인 고객DB 문자 알림 감지`를 켜야 자동 감지가 동작합니다.

## v2.0 알림 감지 방식

- 외부 설치 앱에 제한되는 RECEIVE_SMS 권한을 사용하지 않습니다.
- 삼성 메시지와 Google 메시지의 SMS 및 채팅+ 알림을 감지합니다.
- 통인CS·이사·방문견적 관련 키워드와 고객 신호가 함께 있는 메시지만 저장합니다.
- 은행 알림, 인증번호, 일반 대화는 고객DB로 가져오지 않습니다.
